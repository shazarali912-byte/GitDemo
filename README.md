# Weather Application 🌤️

A desktop weather application developed in Python using the PyQt5 framework. This application connects to the OpenWeatherMap API to fetch and display real-time weather information for any city worldwide.

## Features
- **Real-time Data:** Fetches current temperature, weather conditions, and descriptions.
- **User-Friendly UI:** Built with PyQt5 for a clean and responsive desktop interface.
- **Error Handling:** Provides dynamic alerts if a city is not found or if there is an API connection issue.

## Technologies Used
- Python 3
- PyQt5 (GUI Framework)
- Requests (API Integration)
- OpenWeatherMap API
